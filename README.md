# E-Commerce Sales Dashboard (Power BI)

## Project Overview
This project analyzes e-commerce sales data using Power BI to provide insights into revenue, orders, payment methods, product categories, customer locations, and order status.

## Dashboard Features
- Total Revenue
- Total Orders
- Revenue Trend
- Top 10 Product Categories
- Payment Type Distribution
- Customer State Analysis
- Order Status Analysis

## Tools Used
- Power BI
- SQL
- Python
